# App Shell and Design System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the eight-tab POC editor with a themed, four-destination phone app (Design, Library, Send, Account) without changing any editing, storage or sending logic.

**Architecture:** Only the UI layer changes. A new `ui/` tree (theme, components, nav, one package per destination) wraps the existing composables. `EditorState`, `Store`, `SendController`, `Sender`, `PreviewPane`, `SlotDragEditor`, `FieldHelpers` logic and `ColourField` parsing stay. Navigation is plain state (an enum plus `rememberSaveable`, `BackHandler`, `AnimatedContent`); no Navigation Compose dependency.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01, Material 3), AGP 8.9.1, JUnit4, Compose UI test. One bundled OFL variable font.

**Spec:** `docs/superpowers/specs/2026-10-09-app-shell-design.md` (parents: `2026-10-08-builder-app-design.md`). Siblings that build on this plan: `2026-10-09-onboarding-design.md`, `2026-10-09-accounts-sync-design.md`.

## Global Constraints

- Phone `minSdk` 28, `compileSdk` 36, `targetSdk` 35, Java 17 (as in `phone/build.gradle.kts`). Kotlin package root `com.seyedjafari.analogplus.phone`.
- New UI lives under `com.seyedjafari.analogplus.phone.ui.{theme,components,nav,design,library,send,account}`; logic files stay in the root package.
- No raw colours, text sizes or dp literals in screens: use `AnalogTheme` colour roles, `MaterialTheme.typography`, and `Spacing`.
- Dynamic colour (Material You) is **off**. Follow the system dark mode. Text contrast at least WCAG AA (4.5:1).
- Touch targets at least 48 dp; every icon-only control has a content description; text must survive 200 % font scale.
- All animations go through `Motion` and snap (duration 0) when the system animator scale is 0.
- Colours stay `#AARRGGBB`; the 8-slot cap, clamping and validation messages are unchanged.
- Existing test tags in `Tags.kt` keep their names and meaning wherever the control survives. JVM tests (`StoreTest`, `SendControllerTest`, `FieldHelpersTest`, `SlotGeometryTest`, `QrCodeTest`, `LinkDialogTest`, `SenderTest`) must pass without edits.
- Never `git push`. Commit locally; no Claude attribution lines in commit messages.
- Gradle file watching misses edits under `/private/tmp`: check the APK is newer than the source.

## Review Focus

1. **Rotation and process death** on every destination: selected destination, selected Design section and Library section survive (`rememberSaveable`); the editor design is unaffected (lives in `AppModel`). Tested in Task 11.
2. **Link or QR arriving while on another destination** (including during a send): the confirm dialog shows on top of any destination and never replaces the design silently. Tested in Task 9.
3. **Back button**: from Library/Send/Account goes to Design, from Design leaves the app; a dialog consumes back first. Tested in Task 4.
4. **Font scale 2.0 and animations disabled** on the Send and Design screens: nothing clipped that blocks a primary action; no animation runs. Tested in Task 10.
5. **Send in flight while switching destinations**: the send continues (controller lives in `AppModel`), the Send destination shows its progress when returned to, and the Design shortcut does not start a second send. Tested in Task 7.

`ui/theme/Contrast.kt`:

```kotlin
package com.seyedjafari.analogplus.phone.ui.theme

import kotlin.math.pow

private fun channel(c: Int): Double {
    val s = c / 255.0
    return if (s <= 0.03928) s / 12.92 else ((s + 0.055) / 1.055).pow(2.4)
}

private fun luminance(argb: Int): Double {
    val r = (argb shr 16) and 0xFF
    val g = (argb shr 8) and 0xFF
    val b = argb and 0xFF
    return 0.2126 * channel(r) + 0.7152 * channel(g) + 0.0722 * channel(b)
}

/** WCAG 2.x contrast ratio (1.0 to 21.0) of two opaque ARGB colours. */
fun contrastRatio(foreground: Int, background: Int): Double {
    val a = luminance(foreground)
    val b = luminance(background)
    return (maxOf(a, b) + 0.05) / (minOf(a, b) + 0.05)
}
```

private val DarkScheme = darkColorScheme(
    primary = c(Palette.darkPrimary), onPrimary = c(Palette.darkOnPrimary),
    primaryContainer = c(Palette.darkPrimaryContainer), onPrimaryContainer = c(Palette.darkOnPrimaryContainer),
    background = c(Palette.darkBackground), onBackground = c(Palette.darkOnSurface),
    surface = c(Palette.darkSurface), onSurface = c(Palette.darkOnSurface),
    surfaceVariant = c(Palette.darkSurfaceVariant), onSurfaceVariant = c(Palette.darkOnSurfaceVariant),
    outline = c(Palette.darkOutline), error = c(Palette.darkError),
)

private val AnalogShapes = Shapes(
    extraSmall = RoundedCornerShape(6.dp), small = RoundedCornerShape(10.dp), medium = RoundedCornerShape(16.dp),
    large = RoundedCornerShape(24.dp), extraLarge = RoundedCornerShape(32.dp),
)

/** The app theme. Dynamic colour is deliberately not used: the brand stays the same on every phone. */
@Composable
fun AnalogTheme(darkTheme: Boolean = isSystemInDarkTheme(), content: @Composable () -> Unit) {
    MaterialTheme(
        colorScheme = if (darkTheme) DarkScheme else LightScheme,
        shapes = AnalogShapes,
        content = content,

}

`ui/theme/Motion.kt`:

```kotlin
package com.seyedjafari.analogplus.phone.ui.theme

import android.provider.Settings
import androidx.compose.animation.core.CubicBezierEasing
import androidx.compose.animation.core.Easing
import androidx.compose.animation.core.FiniteAnimationSpec
import androidx.compose.animation.core.snap
import androidx.compose.animation.core.tween
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.platform.LocalContext

object Motion {
    const val SHORT = 200
    const val MEDIUM = 300
    const val LONG = 500
    val Standard: Easing = CubicBezierEasing(0.2f, 0f, 0f, 1f)
}

/** 0 when the system has animations switched off (animator scale 0 or invalid), otherwise [baseMs]. */
fun motionDuration(baseMs: Int, animatorScale: Float): Int =
    if (animatorScale.isNaN() || animatorScale <= 0f) 0 else baseMs

/** The system "animator duration scale" (Developer options / Remove animations). 1f when it cannot be read. */
@Composable
fun rememberAnimationScale(): Float {
    val resolver = LocalContext.current.contentResolver
    return remember {
        try { Settings.Global.getFloat(resolver, Settings.Global.ANIMATOR_DURATION_SCALE, 1f) } catch (e: Exception) { 1f }
    }
}

/** A tween with the shared easing, or a snap when animations are off. */
@Composable
fun <T> motionSpec(baseMs: Int = Motion.MEDIUM): FiniteAnimationSpec<T> {
    val ms = motionDuration(baseMs, rememberAnimationScale())
    return if (ms == 0) snap() else tween(ms, easing = Motion.Standard)
}
```

package com.seyedjafari.analogplus.phone.ui.send

import android.content.Context
import com.seyedjafari.analogplus.phone.GmsTransport
import com.seyedjafari.analogplus.phone.WatchTransport
import kotlin.coroutines.cancellation.CancellationException

enum class CheckStatus { CHECKING, OK, ACTION_NEEDED, UNKNOWN }

data class WatchStatus(val paired: CheckStatus, val appInstalled: CheckStatus) {
    companion object { val CHECKING = WatchStatus(CheckStatus.CHECKING, CheckStatus.CHECKING) }
}

fun interface WatchStatusChecker { suspend fun check(): WatchStatus }

class TransportWatchStatusChecker(private val transport: WatchTransport) : WatchStatusChecker {
    override suspend fun check(): WatchStatus = try {
        when {
            transport.nodesWithApp().isNotEmpty() -> WatchStatus(CheckStatus.OK, CheckStatus.OK)
            transport.connectedNodeIds().isNotEmpty() -> WatchStatus(CheckStatus.OK, CheckStatus.ACTION_NEEDED)
            else -> WatchStatus(CheckStatus.ACTION_NEEDED, CheckStatus.UNKNOWN)
        }
    } catch (e: CancellationException) {
        throw e
    } catch (e: Exception) {
        WatchStatus(CheckStatus.UNKNOWN, CheckStatus.UNKNOWN)
    }
}

/** The real checker. `GmsTransport` is `internal` to the module, which this file is part of. */
fun gmsWatchStatusChecker(context: Context): WatchStatusChecker = TransportWatchStatusChecker(GmsTransport(context.applicationContext))

        val state = EditorState(DesignSettings())
        val store = testStore()

        restoration.setContent { AppShell(state, store, send, watchReady, null) {} }

        rule.onNodeWithTag(Tags.field("minuteTickWidth")).assertExists()   // the Dial section is still selected
    }

    @Test fun sendKeepsRunningWhenSwitchingDestinations() {
        val started = CountDownLatch(1)
        val release = CountDownLatch(1)
        val state = EditorState(DesignSettings())
        val store = testStore()
        val send = testSend(store, FaceBuilder { _, _ ->
            started.countDown()
            release.await(30, TimeUnit.SECONDS)
            throw FaceBuildException(listOf("released by the test"))
        })
        rule.setContent { AppShell(state, store, send, watchReady, null) {} }
        rule.onNodeWithTag(Tags.field("design_send")).performClick()          // starts the send and opens Send

        rule.onNodeWithTag(Destination.SEND.tag).performClick()
        rule.onNodeWithTag(Tags.SEND_STATUS).assertTextEquals("Building the face...")
        release.countDown()
        rule.waitUntil(10_000) { send.state.value is SendUi.Error }
        rule.onNodeWithTag(Tags.SEND_BUTTON).assertExists()
    }
