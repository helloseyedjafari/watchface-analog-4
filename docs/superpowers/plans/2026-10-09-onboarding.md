# Animated Onboarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A first run that teaches what the app does and gets a new user to a watch that is paired, a permission they understand and a starting template, with Lottie animations, skippable and resumable, never shown to an existing user and never twice unless asked.

**Architecture:** Onboarding state is a sealed type (`NotStarted`, `InProgress(page)`, `Completed`, `Skipped`) persisted as one string in `Store`; an `OnboardingController` (a plain class with `StateFlow`s, living in `AppModel`) owns the transitions. `AppShell` shows `OnboardingScreen` (pager, progress, Skip, Back, five pages) as a gate before `AppNav` while the state is active. The pairing page reuses `WatchStatusChecker` from `ui/send` (app-shell plan, Task 7). Four Lottie files are generated by a Python script from the watch-face geometry and recoloured at run time with dynamic properties. The optional sign-in page is a hidden stub: a composable slot behind `OnboardingConfig.accountsAvailable`, which the accounts plan fills and flips.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01, Material 3), `com.airbnb.android:lottie-compose:6.7.1`, Python 3 (stdlib `json`/`unittest`, plus the repo's Pillow for `gen_assets`), JUnit4 + `kotlinx-coroutines-test` (JVM), Compose UI test (instrumented).

**Spec:** `docs/superpowers/specs/2026-10-09-onboarding-design.md` (parents: `2026-10-08-builder-app-design.md`, `2026-10-09-app-shell-design.md`; the last page is filled by `2026-10-09-accounts-sync-design.md`).

**Depends on:** `docs/superpowers/plans/2026-10-09-app-shell.md`, implemented and merged first. This plan uses its exact names: `AnalogTheme`, `Palette`, `Spacing`, `Motion`, `motionSpec`, `motionDuration`, `rememberAnimationScale`, `SectionCard`, `PrimaryButton`, `SecondaryButton`, `StatusPill`, `StatusKind`, `ErrorBanner`, `Destination`, `AppNav(content, startAt, modifier)`, `AppShell(state, store, send, watch, pendingLink, onPendingLinkResolved)`, `AccountScreen`, `LibraryScreen`, `CheckStatus`, `WatchStatus(paired, appInstalled)`, `WatchStatusChecker`, `TransportWatchStatusChecker`, `gmsWatchStatusChecker(context)`. Where this plan needs more than plan 1 provides, a task here changes it (Tasks 7, 8, 11) and says so.

- Dependencies are plain strings in `phone/build.gradle.kts`; there is no version catalog. Lottie is pinned to `6.7.1` (the latest on Maven Central on 2026-10-09; its POM imports Compose BOM 2024.02.01 and kotlin-stdlib 1.9.22, both older than the app's, so the app's versions win). - Work in a git worktree, merge to `main` locally when green, never `git push`. Commit messages carry no `Co-Authored-By` or Claude lines.

## Review Focus

1. **Existing user and first-run autosave.** A POC user (saved designs, a current design, a version counter or a sent-key fingerprint) must go straight to the editor and be recorded as `SKIPPED`. Conversely `AppModel` autosaves the default design 400 ms after the first launch, so a brand-new user must not look like a POC user on the next launch: the decision is stored on the first launch. Tested in Task 2 (JVM) and Task 11.
2. **Resume.** Rotation and process death mid-onboarding come back on the same page; a stored page that is not in the page list (`BACKUP` while accounts are off) lands on the last visible page, not a crash. Tested in Tasks 3 and 12.
3. **Pairing check that never answers or cannot tell.** GMS missing or slow gives `UNKNOWN` ("Could not check"), never "Not found"; a hanging check times out after 10 s; a user with no watch can always continue and finish, and gets no Send tip. Tested in Tasks 7 and 12.
4. **Reduced motion and background.** Animator scale 0 shows each animation's last frame (no loop) and the pager snaps; a page that is not visible, or an app in the background, pauses. Tested in Tasks 6 and 12.
5. **Do not lose the user's work.** Picking a template over an edited design asks first and Cancel keeps the edit; Skip and Finish never touch the design; a shared link arriving during onboarding shows the confirm dialog on top and never replaces silently; text and the primary button survive font scale 2.0. Tested in Tasks 8, 11 and 12.

```kotlin
package com.seyedjafari.analogplus.phone

/** The pages of first-run setup, in order. [BACKUP] is only shown when accounts ship ([OnboardingConfig.accountsAvailable]). */
enum class OnboardingPage { WELCOME, PAIR, PERMISSION, TEMPLATE, BACKUP }

object OnboardingConfig {
    /**
     * Whether the optional sign-in / passphrase page exists. The accounts plan sets this to true when sign-in and sync
     * ship (and supplies the page through `OnboardingHost.backupPage`). Not `const`, so tests and the compiler do not
     * treat the page list as a constant.
     */
    val accountsAvailable: Boolean = false
}

fun onboardingPages(accountsAvailable: Boolean): List<OnboardingPage> =
    if (accountsAvailable) OnboardingPage.entries.toList() else OnboardingPage.entries - OnboardingPage.BACKUP

/**
 * Where first-run setup stands. Completed and Skipped are different on purpose: both can be re-run from Account, but
 * only a completed run says the user saw every page.
 */
sealed interface OnboardingState {
    data object NotStarted : OnboardingState
    data class InProgress(val page: OnboardingPage) : OnboardingState
    data object Completed : OnboardingState
    data object Skipped : OnboardingState
}

/** True while the onboarding screen should be showing. */
val OnboardingState.isActive: Boolean
    get() = this is OnboardingState.NotStarted || this is OnboardingState.InProgress

private const val IN_PROGRESS_PREFIX = "IN_PROGRESS:"

fun OnboardingState.encode(): String = when (this) {
    OnboardingState.NotStarted -> "NOT_STARTED"
    is OnboardingState.InProgress -> IN_PROGRESS_PREFIX + page.name
    OnboardingState.Completed -> "COMPLETED"
    OnboardingState.Skipped -> "SKIPPED"
}

/**
 * The state [text] encodes, or null when [text] is null or not something [encode] wrote (a corrupt or future value is
 * treated as "never decided"). An in-progress state whose page is unknown resumes at the first page.
 */
fun decodeOnboardingState(text: String?): OnboardingState? = when {
    text == null -> null
    text == "NOT_STARTED" -> OnboardingState.NotStarted
    text == "COMPLETED" -> OnboardingState.Completed
    text == "SKIPPED" -> OnboardingState.Skipped
    text.startsWith(IN_PROGRESS_PREFIX) -> {
        val name = text.removePrefix(IN_PROGRESS_PREFIX)
        OnboardingState.InProgress(OnboardingPage.entries.firstOrNull { it.name == name } ?: OnboardingPage.WELCOME)
    }
    else -> null
}
```

```kotlin
    // ---- onboarding -----------------------------------------------------------------------------------------

    /** The stored onboarding state, or null when none was ever stored (or the stored text cannot be read). */
    fun onboardingState(): OnboardingState? = synchronized(LOCK) { decodeOnboardingState(kv.getString(KEY_ONBOARDING)) }

    fun saveOnboardingState(s: OnboardingState) = synchronized(LOCK) { kv.putString(KEY_ONBOARDING, s.encode()) }

    /**
     * True when this install was used before onboarding existed: a current design, saved designs, a face version or a
     * sent-key fingerprint is on disk. Only meaningful BEFORE the first autosave of a new install, which is why
     * [resolveOnboardingState] stores its decision at once.
     */
    fun hasPriorUse(): Boolean = synchronized(LOCK) {
        kv.getString(KEY_CURRENT) != null || readSaved().isNotEmpty() ||
            kv.getLong(KEY_VERSION, 0L) > 0L || kv.getString(KEY_SENT_FINGERPRINT) != null
    }

    /**
     * The onboarding state to start with. A stored state wins. Otherwise: [OnboardingState.Skipped] for an existing
     * user (an update from the POC must never be blocked), [OnboardingState.NotStarted] for a new one; the decision is
     * written so the autosave of the default design that follows the first launch cannot flip it later.
     */
    fun resolveOnboardingState(): OnboardingState = synchronized(LOCK) {
        onboardingState() ?: (if (hasPriorUse()) OnboardingState.Skipped else OnboardingState.NotStarted)
            .also { saveOnboardingState(it) }
    }
```

```kotlin
    val sendTipVisible: StateFlow<Boolean>        // one-time "open Send" tip after finishing with a watch confirmed ready

    fun skip()        // Skipped
    fun restart()     // InProgress(first page), from Completed or Skipped ("Run setup again")
    fun dismissTip()
}
```

```kotlin
package com.seyedjafari.analogplus.phone

import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow

/**
 * Owns first-run setup: what state it is in, how it moves between pages, and the one-time "open Send" tip.
 * Lives in `AppModel`, so rotation keeps it; every transition is stored first, so process death resumes at the page.
 */
class OnboardingController(
    private val store: Store,
    val pages: List<OnboardingPage> = onboardingPages(OnboardingConfig.accountsAvailable),
) {
    init { require(pages.isNotEmpty()) { "onboarding needs at least one page" } }

    // Decided once, before AppModel's first autosave of the default design (see Store.resolveOnboardingState).
    private val _state = MutableStateFlow(store.resolveOnboardingState())
    val state: StateFlow<OnboardingState> = _state.asStateFlow()

    private val _sendTip = MutableStateFlow(false)
    /** True after finishing (or skipping) when the pairing page had positively confirmed a watch with the app. */
    val sendTipVisible: StateFlow<Boolean> = _sendTip.asStateFlow()

    /** Two genuine states: positively confirmed ready, or not (unknown counts as not confirmed). */
    private var watchReady = false

    /** The page to show for [s]: the stored page when it exists in [pages], else the last page; the first page otherwise. */
    fun pageFor(s: OnboardingState): OnboardingPage = when (s) {
        is OnboardingState.InProgress -> if (s.page in pages) s.page else pages.last()
        else -> pages.first()
    }

    fun currentPage(): OnboardingPage = pageFor(_state.value)

    fun reportWatchReady(ready: Boolean) { watchReady = ready }

    fun advance() {
        val i = pages.indexOf(currentPage())
        if (i >= pages.lastIndex) finish(OnboardingState.Completed) else set(OnboardingState.InProgress(pages[i + 1]))
    }

    fun back() {
        val i = pages.indexOf(currentPage())
        if (i > 0) set(OnboardingState.InProgress(pages[i - 1]))
    }

    fun skip() = finish(OnboardingState.Skipped)

    /** "Run setup again" from Account: from Completed or Skipped (or mid-run) back to the first page. */
    fun restart() {
        _sendTip.value = false
        watchReady = false
        set(OnboardingState.InProgress(pages.first()))
    }

    fun dismissTip() { _sendTip.value = false }

    private fun finish(s: OnboardingState) {
        _sendTip.value = watchReady
        set(s)
    }

    private fun set(s: OnboardingState) {
        if (_state.value == s) return
        store.saveOnboardingState(s)
        _state.value = s
    }
}
```

```python
#!/usr/bin/env python3
"""Generate the four onboarding Lottie animations (phone/src/main/res/raw/onboarding_*.json).

The animations are drawn from the watch-face geometry: hand lengths and widths and the hour-dot ring come from
gen_assets, the four complication slot boxes come from build_face. The composition is the 480 x 480 reference
capture, so reference pixels are composition pixels; everything is drawn around the centre and shrunk by SCALE so the
outer dots keep a margin.

Colours: every fill and stroke sits in a group named accent / ink / track / onaccent. The app recolours those groups
at run time with Lottie dynamic properties (brand colours, light and dark). The colours written here are deliberately
loud placeholders (magenta, yellow, cyan, orange): if a group is ever not matched by the app, it shows.

    python3 tools/gen_onboarding_lottie.py            # writes the four files
    python3 tools/gen_onboarding_lottie.py --out DIR  # writes them somewhere else
"""
import argparse
import json
import math
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import build_face as bf  # noqa: E402
import gen_assets as g  # noqa: E402

ROOT = Path(__file__).resolve().parent.parent
OUT = ROOT / "phone" / "src" / "main" / "res" / "raw"

FPS = 30
SIZE = g.REF
C = SIZE / 2
SCALE = 0.86
RING_R, RING_W = 200.0, 16.0

PLACEHOLDER = {
    "accent": [1, 0, 1, 1],
    "ink": [1, 0.9, 0, 1],
    "track": [0, 0.9, 0.9, 1],
    "onaccent": [1, 0.5, 0, 1],
}

EASE_I = {"x": [0.3], "y": [1]}
EASE_O = {"x": [0.2], "y": [0]}
LIN_I = {"x": [1], "y": [1]}
LIN_O = {"x": [0], "y": [0]}


def r(v):
    return round(float(v), 3)


# ---- properties -----------------------------------------------------------------------------------------------

def num(v):
    return {"a": 0, "k": r(v)}


def vec(*v):
    return {"a": 0, "k": [r(x) for x in v]}


def anim(points, linear=False):
    """points: [(frame, value)], value a number or a list of numbers. Frames strictly increase."""
    keys = []
    for n, (t, v) in enumerate(points):
        s = [r(x) for x in v] if isinstance(v, (list, tuple)) else [r(v)]
        k = {"t": t, "s": s}
        if n < len(points) - 1:
            k["i"], k["o"] = (LIN_I, LIN_O) if linear else (EASE_I, EASE_O)
        keys.append(k)
    return {"a": 1, "k": keys}


# ---- shapes ---------------------------------------------------------------------------------------------------

def ellipse(radius, cx=0.0, cy=0.0):
    return {"ty": "el", "d": 1, "s": vec(2 * radius, 2 * radius), "p": vec(cx, cy), "nm": "Ellipse"}


def rrect(w, h, radius, cx=0.0, cy=0.0):
    return {"ty": "rc", "d": 1, "s": vec(w, h), "p": vec(cx, cy), "r": num(radius), "nm": "Rect"}


def path(points, closed=False):
    zero = [[0, 0] for _ in points]
    return {"ty": "sh", "ks": {"a": 0, "k": {"i": zero, "o": zero, "v": [[r(x), r(y)] for x, y in points], "c": closed}}, "nm": "Path"}


def fill(name, opacity=100):
    return {"ty": "fl", "c": {"a": 0, "k": PLACEHOLDER[name]}, "o": num(opacity), "r": 1, "nm": "Fill"}


def stroke(name, width, cap=2, opacity=100):
    """cap: 1 butt, 2 round."""
    return {"ty": "st", "c": {"a": 0, "k": PLACEHOLDER[name]}, "o": num(opacity), "w": num(width), "lc": cap, "lj": 2, "nm": "Stroke"}


def trim(start, end):
    """start and end are percentages as Lottie properties."""
    return {"ty": "tm", "s": start, "e": end, "o": num(0), "m": 1, "nm": "Trim"}


def group(name, items):
    tr = {"ty": "tr", "p": vec(0, 0), "a": vec(0, 0), "s": vec(100, 100), "r": num(0), "o": num(100),
          "sk": num(0), "sa": num(0), "nm": "Transform"}
    return {"ty": "gr", "nm": name, "it": items + [tr], "np": len(items), "cix": 2, "bm": 0, "ix": 1,
            "mn": "ADBE Vector Group", "hd": False}


def layer(ind, name, shapes, op, pos=(C, C), scale_anim=None, pos_anim=None, rot=None, opacity=None):
    ks = {
        "o": opacity or num(100),
        "r": rot or num(0),
        "p": pos_anim or vec(pos[0], pos[1], 0),
        "a": vec(0, 0, 0),
        "s": scale_anim or vec(SCALE * 100, SCALE * 100, 100),
    }
    return {"ddd": 0, "ind": ind, "ty": 4, "nm": name, "sr": 1, "ks": ks, "ao": 0, "shapes": shapes,
            "ip": 0, "op": op, "st": 0, "bm": 0}


def composition(name, op, layers):
    return {"v": "5.7.0", "fr": FPS, "ip": 0, "op": op, "w": SIZE, "h": SIZE, "nm": name, "ddd": 0,
            "assets": [], "layers": layers}


def to_comp(x, y):
    """A point in reference pixels (centre 240,240) -> composition pixels after the SCALE shrink."""
    return C + (x - C) * SCALE, C + (y - C) * SCALE


# ---- pieces of the face ----------------------------------------------------------------------------------------

def hour_dots(name="track"):
    items = []
    for h in range(12):
        a = math.radians(h * 30)
        items.append(ellipse(g.DOT_RADIUS, g.DOT_R * math.sin(a), -g.DOT_R * math.cos(a)))
    return group(name, items + [fill(name)])


def hand(length, tail, width, name):
    return group(name, [path([(0, tail), (0, -length)]), stroke(name, width)])


def cap():
    return [group("onaccent", [ellipse(3.5), fill("onaccent")]), group("accent", [ellipse(g.CAP_RED_R), fill("accent")])]


def ring_track():
    return group("track", [ellipse(RING_R), stroke("track", RING_W, cap=1, opacity=30)])


def slot_geometry(slot):
    cx, cy = (slot.x + slot.w / 2) / bf.F, (slot.y + slot.h / 2) / bf.F
    return cx, cy, slot.w / bf.F, slot.h / bf.F


# ---- the four animations ---------------------------------------------------------------------------------------

def welcome():
    """Loop (8 s): the hands sweep, the ring morphs full -> halves -> quarters -> full, the slots pop in and out."""
    op = 240
    times = [(0, 40), (60, 100), (120, 160), (180, 240)]
    layouts = [0, 1, 2, 0]                                  # which of the three (start, end) pairs below: full, halves, quarters
    layout = {                                              # arc -> (start %, end %) per layout
        0: [(0, 100), (0, 48), (0, 23)],
        1: [(50, 50), (50, 98), (25, 48)],
        2: [(50, 50), (50, 50), (50, 73)],
        3: [(75, 75), (75, 75), (75, 98)],
    }
    arcs = []
    for i in range(4):
        s_pts, e_pts = [], []
        for (t0, t1), li in zip(times, layouts):
            s, e = layout[i][li]
            s_pts += [(t0, s), (t1, s)]
            e_pts += [(t0, e), (t1, e)]
        name = "accent" if i % 2 == 0 else "ink"
        arcs.append(group(name, [ellipse(RING_R), trim(anim(s_pts), anim(e_pts)), stroke(name, RING_W, cap=1)]))
    layers = [
        layer(1, "cap", cap(), op),
        layer(2, "second hand", [hand(g.SECOND_LEN, g.SECOND_TAIL, g.SECOND_W, "accent")], op, rot=anim([(0, 0), (op, 1440)], linear=True)),
        layer(3, "minute hand", [hand(g.MINUTE_LEN, g.HAND_BASE, g.HAND_W, "ink")], op, rot=anim([(0, 0), (op, 720)], linear=True)),
        layer(4, "hour hand", [hand(g.HOUR_LEN, g.HAND_BASE, g.HAND_W, "ink")], op, rot=anim([(0, 0), (op, 360)], linear=True)),
    ]
    full = SCALE * 100
    for n, slot in enumerate(bf.SLOTS):
        cx, cy, w, h = slot_geometry(slot)
        t0 = 70 + 8 * n

        al = anim([(0, alpha(mid_u)), (edge, alpha(1)), (edge + 1, alpha(0)), (op, alpha(mid_u))])
```

```kotlin
 * Reduced motion (animator scale 0 or invalid) wins over everything: the last frame is shown still. Otherwise an
 * animation plays only while its page is visible and the app is in the foreground.
 */
fun resolveAnimationMode(animatorScale: Float, pageVisible: Boolean, appForeground: Boolean): AnimationMode = when {
    motionDuration(Motion.MEDIUM, animatorScale) == 0 -> AnimationMode.STATIC_LAST_FRAME
    !pageVisible || !appForeground -> AnimationMode.PAUSED
    else -> AnimationMode.PLAYING
}
```

```kotlin
package com.seyedjafari.analogplus.phone.ui.onboarding
```

```kotlin
import com.seyedjafari.analogplus.phone.ui.components.StatusKind
```
```kotlin
import com.seyedjafari.analogplus.phone.ui.send.CheckStatus
import com.seyedjafari.analogplus.phone.ui.send.WatchStatus
```

```kotlin
import kotlin.coroutines.cancellation.CancellationException
import kotlinx.coroutines.withTimeoutOrNull

const val CHECK_TIMEOUT_MS = 10_000L

/** What the pairing page tells the user to do next. */
enum class PairStep { CHECKING, ALL_READY, OPEN_WEARABLE_APP, INSTALL_WATCH_APP, COULD_NOT_CHECK }

fun pairStep(s: WatchStatus): PairStep = when {
    s.paired == CheckStatus.CHECKING || s.appInstalled == CheckStatus.CHECKING -> PairStep.CHECKING
    s.paired == CheckStatus.OK && s.appInstalled == CheckStatus.OK -> PairStep.ALL_READY
    s.paired == CheckStatus.ACTION_NEEDED -> PairStep.OPEN_WEARABLE_APP
    s.paired == CheckStatus.OK && s.appInstalled == CheckStatus.ACTION_NEEDED -> PairStep.INSTALL_WATCH_APP
    else -> PairStep.COULD_NOT_CHECK
}

fun PairStep.advice(): String? = when (this) {
    PairStep.CHECKING -> null
    PairStep.ALL_READY -> OnboardingText.READY
    PairStep.OPEN_WEARABLE_APP -> OnboardingText.OPEN_WEARABLE_APP
    PairStep.INSTALL_WATCH_APP -> OnboardingText.INSTALL_WATCH_APP
    PairStep.COULD_NOT_CHECK -> OnboardingText.COULD_NOT_CHECK
}

/** Only a positively confirmed watch with the app counts; unknown, checking and missing do not. */
fun watchIsReady(s: WatchStatus): Boolean = pairStep(s) == PairStep.ALL_READY

data class PairRow(val id: String, val label: String, val kind: StatusKind, val text: String)

fun pairRows(s: WatchStatus): List<PairRow> {
    val watch = PairRow("watch", OnboardingText.ROW_WATCH, s.paired.statusKind(), s.paired.statusText("Found", "Not found"))
    val app = if (s.paired == CheckStatus.ACTION_NEEDED) {
        PairRow("app", OnboardingText.ROW_APP, StatusKind.NEUTRAL, "Needs a paired watch")
    } else {
        PairRow("app", OnboardingText.ROW_APP, s.appInstalled.statusKind(), s.appInstalled.statusText("Installed", "Not installed"))
    }
    return listOf(watch, app)
}

/** The check, bounded: no answer within [timeoutMs] or an exception is "could not check", never a negative result. */
suspend fun WatchStatusChecker.checkWithTimeout(timeoutMs: Long = CHECK_TIMEOUT_MS): WatchStatus = try {
    withTimeoutOrNull(timeoutMs) { check() } ?: WatchStatus(CheckStatus.UNKNOWN, CheckStatus.UNKNOWN)
} catch (e: CancellationException) {
    throw e
} catch (e: Exception) {
    WatchStatus(CheckStatus.UNKNOWN, CheckStatus.UNKNOWN)
}
```

```kotlin
/**
 * A design that matches a built-in template can be swapped for another without losing anything. Anything else (edited,
 * loaded from a link, with a photo) is the user's work and is only replaced after they confirm.
 */
fun needsReplaceConfirmation(current: DesignSettings, target: DesignSettings): Boolean =
    target != current && current !in Templates.all

/** Page 4. Choosing a template sets the current design, under the same replace rule as Library. */
@Composable
fun TemplatePage(state: EditorState, modifier: Modifier = Modifier) {
    var pending by remember { mutableStateOf<PendingReplace?>(null) }
    val choose: (DesignSettings) -> Unit = { target ->
        if (target == state.design) {
            // already the design: nothing to do
        } else if (needsReplaceConfirmation(state.design, target)) {
            pending = PendingReplace(target.name, target)
        } else {
            state.replace(target)
        }
    }
    ReplaceDialog(pending, onConfirm = { state.replace(it.design); pending = null }, onCancel = { pending = null })

    PageLayout(OnboardingText.TEMPLATE_TITLE, modifier) {
        Text(
            OnboardingText.TEMPLATE_BODY, style = MaterialTheme.typography.bodyLarge,
            color = MaterialTheme.colorScheme.onSurfaceVariant, textAlign = TextAlign.Center,
        )
        Templates.all.chunked(2).forEach { row ->
            Row(Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.spacedBy(Spacing.md)) {
                row.forEach { t -> TemplateChoice(t, selected = t == state.design, onClick = { choose(t) }, modifier = Modifier.weight(1f)) }
                if (row.size == 1) Spacer(Modifier.weight(1f))
            }
        }
    }
}

@Composable
private fun TemplateChoice(template: DesignSettings, selected: Boolean, onClick: () -> Unit, modifier: Modifier) {
    Card(
        modifier.selectable(selected = selected, onClick = onClick, role = Role.RadioButton).testTag(Tags.onboardingTemplate(template.name)),
        border = if (selected) BorderStroke(Spacing.xs / 2, MaterialTheme.colorScheme.primary) else null,
    ) {
        Column(Modifier.padding(Spacing.sm).fillMaxWidth(), horizontalAlignment = Alignment.CenterHorizontally) {
            DesignThumbnail(template, THUMBNAIL_SIZE)
            Text(template.name, style = MaterialTheme.typography.labelLarge, modifier = Modifier.padding(top = Spacing.xs))
            // the border alone would be colour; the word says it too
            Text(
                if (selected) OnboardingText.SELECTED else "", style = MaterialTheme.typography.labelSmall,
                color = MaterialTheme.colorScheme.primary,
            )
        }
    }
}
```

```kotlin
/** What [com.seyedjafari.analogplus.phone.AppShell] needs to show onboarding; the accounts plan passes its own [backupPage]. */
class OnboardingHost(
    val controller: OnboardingController,
    val backupPage: BackupPageSlot = { onDone -> BackupPagePlaceholder(onDone) },
)

/**
 * First-run setup: pages in a pager that only the buttons and Back move (the controller is the single source of truth,
 * so a rotation or process restart shows the stored page), a progress line, Skip on every page and Back from page 2.
 */
@Composable
fun OnboardingScreen(
    controller: OnboardingController,
    backupPage: BackupPageSlot,
    state: EditorState,
    watch: WatchStatusChecker,
    modifier: Modifier = Modifier,
) {
    val current by controller.state.collectAsState()
    val pages = controller.pages
    val page = controller.pageFor(current)
    val index = pages.indexOf(page)
    val pager = rememberPagerState(initialPage = index) { pages.size }
    val scrollSpec = motionSpec<Float>(Motion.MEDIUM)
    LaunchedEffect(index) {
        if (pager.currentPage != index) pager.animateScrollToPage(index, animationSpec = scrollSpec)
    }
    BackHandler(enabled = index > 0) { controller.back() }

    Column(modifier.fillMaxSize().testTag(Tags.ONBOARDING_ROOT)) {
        Row(
            Modifier.fillMaxWidth().padding(horizontal = Spacing.lg),
            horizontalArrangement = Arrangement.spacedBy(Spacing.md), verticalAlignment = Alignment.CenterVertically,
        ) {
            Column(Modifier.weight(1f), verticalArrangement = Arrangement.spacedBy(Spacing.xs)) {
                Text(
                    OnboardingText.stepOf(index, pages.size), style = MaterialTheme.typography.labelMedium,
                    color = MaterialTheme.colorScheme.onSurfaceVariant, modifier = Modifier.testTag(Tags.ONBOARDING_PROGRESS),
                )
                val progress by animateFloatAsState((index + 1f) / pages.size, motionSpec(Motion.MEDIUM), label = "onboarding-progress")
                LinearProgressIndicator(progress = { progress }, Modifier.fillMaxWidth())
            }
            TextButton(onClick = controller::skip, modifier = Modifier.heightIn(min = Spacing.minTouch).testTag(Tags.ONBOARDING_SKIP)) {
                Text("Skip")
            }
        }

        HorizontalPager(pager, Modifier.weight(1f), userScrollEnabled = false, key = { pages[it].name }) { i ->
            val visible = i == index
            Box(Modifier.fillMaxSize().testTag(Tags.onboardingPage(pages[i].name.lowercase()))) {
                when (pages[i]) {
                    OnboardingPage.WELCOME -> WelcomePage(visible)
                    OnboardingPage.PAIR -> PairPage(watch, onStatus = { controller.reportWatchReady(watchIsReady(it)) }, pageVisible = visible)
                    OnboardingPage.PERMISSION -> PermissionPage(visible)
                    OnboardingPage.TEMPLATE -> TemplatePage(state)
                    OnboardingPage.BACKUP -> backupPage { controller.advance() }
                }
            }
        }

        val label = OnboardingText.primaryLabel(page, isLast = index == pages.lastIndex)
        Row(
            Modifier.fillMaxWidth().padding(Spacing.lg),
            horizontalArrangement = Arrangement.spacedBy(Spacing.md), verticalAlignment = Alignment.CenterVertically,
        ) {
            if (index > 0) SecondaryButton("Back", controller::back, Modifier.testTag(Tags.ONBOARDING_BACK))
            if (label != null) PrimaryButton(label, controller::advance, Modifier.weight(1f).testTag(Tags.ONBOARDING_NEXT))
        }
    }
}
```
